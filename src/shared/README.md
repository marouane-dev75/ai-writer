# Shared

This directory contains shared components and utilities used across the application.

## Available Shared Modules

### [`i18n/`](i18n/)
Internationalization support with locale management and translation services.

### [`layouts/`](layouts/)
Common layout components like navbar, page container, and dark mode toggle.

### [`theme/`](theme/)
Theme management including CSS variables, context, and storage services.

### [`ui/`](ui/)
Reusable UI components such as buttons, dialogs, inputs, etc.

### [`wdyr/`](wdyr/)
Why Did You Render setup for React development debugging.

# Source

This directory contains the main source code for the React frontend application.

## Contents

### [`App.tsx`](App.tsx)
Main application component that defines the routing structure and renders the global restart prompt overlay.

### [`main.tsx`](main.tsx)
Application entry point that initializes React, sets up providers (Theme, I18n, AppRestart), and renders the App component.

### [`features/`](features/)
Directory containing feature-specific modules organized as self-contained units.

### [`pages/`](pages/)
Directory containing the main page components of the application.

### [`shared/`](shared/)
Directory containing shared components and utilities used across the application.

### [`vite-env.d.ts`](vite-env.d.ts)
TypeScript declarations for Vite environment variables.

# Model Manager

This module provides model management functionality for different AI model providers.

## Structure

- **qwen/** - Qwen model management system (catalog, download, scanning)

## Purpose

The model manager handles:
- Model catalog/registry
- Model downloading from remote sources
- Local model scanning and discovery
- Model lifecycle management

## Current Providers

- **Qwen** - Local Qwen models with GGUF format support

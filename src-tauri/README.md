# Tauri Backend

This directory contains the Tauri backend application code.

## Contents

### [`Cargo.toml`](Cargo.toml)
Rust package manifest with dependencies and build configuration.

### [`tauri.conf.json`](tauri.conf.json)
Tauri configuration file defining app settings, windows, and bundle options.

### [`src/`](src/)
Main Rust source code directory.

### [`build.rs`](build.rs)
Build script for the Tauri application.

### [`capabilities/`](capabilities/)
Tauri capabilities configuration.

### [`icons/`](icons/)
Application icons for different platforms.

### [`gen/`](gen/)
Generated schema files for capabilities auto-completion.

### [`target/`](target/)
Build artifacts directory (generated).

### [`Cargo.lock`](Cargo.lock)
Cargo dependency lock file.

### [`.gitignore`](.gitignore)
Git ignore file for Rust/Tauri specific files.
